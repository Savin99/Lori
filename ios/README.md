# Lori for iOS

Транскрибатор для iPhone: записал или принёс файл — получил текст.

- Рабочая папка приложения — `Documents/Lori/Workspace`, видна в «Файлах»:
  `Recordings/` (диктофон), `Imported/` (принесённые файлы), `Transcripts/` (расшифровки).
- Шесть движков на выбор, переключаются в настройках:
  - **GigaAM v3** — на самом телефоне, через ONNX Runtime. Модель ставится одной кнопкой
    (~225 МБ, RNN-T или CTC), качается с HuggingFace без ключей и регистрации —
    подробности в [design/gigaam/README.md](design/gigaam/README.md).
  - **Whisper large-v3 turbo** — на самом телефоне, через WhisperKit (Core ML). Многоязычный,
    с пунктуацией и таймкодами слов. Папку модели (618 МБ) кладут руками в «Файлы» → Lori →
    `Models`: приложение её не качает — подробности в [design/whisper/README.md](design/whisper/README.md).
  - **Apple** — системное распознавание iOS, без ключей и без пунктуации.
  - **OpenAI** — любой сервис с API как у OpenAI (`/audio/transcriptions`): сам OpenAI, Groq,
    свой whisper-сервер в домашней сети.
  - **Gemini** — `v1beta/interactions` с запасным `generateContent`. По умолчанию
    `gemini-3.5-transcribe` — специализированная на распознавании речи.
  - **ElevenLabs Scribe** — `POST /v1/speech-to-text`, по умолчанию `scribe_v2`. Отправляет
    запись **целиком одним запросом** (сервис берёт до 5 ГБ и 10 часов): резать её нельзя,
    потому что говорящих он нумерует внутри запроса — на стыке частей «S1» стал бы другим
    человеком. Тайминги слов приходят нативно на всю запись.
- Имя модели вписывать не нужно: список приходит от самого сервиса и фильтруется до тех,
  что умеют аудио. Руками задаются только ключ API и словарь. Исключение — ElevenLabs:
  списка моделей распознавания сервис не отдаёт вовсе (`GET /v1/models` у него про синтез
  речи), поэтому там короткий список из документации и кнопки «Обновить» нет.
- Движок не подменяется сам: если выбранный недоступен, приложение говорит, чего не хватает,
  а не отправляет запись куда-нибудь ещё. Локальные движки не выпускают аудио с телефона вовсе.
- Свой **словарь** имён и терминов уходит облачным движкам: OpenAI — штатным полем
  `prompt`, Gemini — структурным полем `custom_vocabulary`, ElevenLabs — полем `keyterms`.
  С таймкодами или говорящими Gemini это поле не принимает (проверено на живом API) — тогда
  словарь автоматически уходит текстом запроса. У ElevenLabs поле платное: словарь добавляет
  20% к стоимости расшифровки, и отправляется он только когда действительно набран.
- **Таймкоды реплик** и **разделение говорящих** — честные переключатели в настройках:
  у Gemini они уходят полями `timestamp_granularities` и `diarization_mode`, у OpenAI
  зависят от модели (таймкоды — whisper, говорящие — diarize-модели). У ElevenLabs работают
  оба и независимо друг от друга — это единственный движок, где так. Где движок не умеет,
  переключатель выключен с объяснением, а не игнорируется молча.
- **«Спроси свой архив»** — вопрос по-русски и ответ по расшифровкам со ссылками на записи.
  Спросить можно по одной записи (меню «…» на экране записи) или по архиву — кнопка со
  звёздочкой в шапке главного экрана, охват «Все» или тема. Отвечает любой сервис с API как
  у OpenAI (`/chat/completions`): сама OpenAI, DeepSeek, Groq, свой сервер. Ключ и адрес —
  «Настройки → Ассистент», отдельно от движка расшифровки. Наружу уходит только текст тех
  расшифровок, по которым спрашивают, и только по нажатию кнопки; аудио не уходит никогда.
  Какие куски отправить, приложение выбирает у себя по совпадению слов вопроса, а если в
  бюджет запроса вошло не всё — говорит об этом прямо в ответе. Ответ разовый: истории нет.
- Ключи API живут только в Keychain телефона; в исходниках и в сборке их нет.
- Длинные записи режутся на части автоматически (кроме ElevenLabs, который берёт запись
  целиком): у OpenAI — под лимит размера запроса,
  у Gemini — под настройку «Длина части» (по умолчанию 10 минут), но не больше предела
  режима: час одним запросом, 30 минут с таймкодами или говорящими. Часть — это не только
  предел сервиса: в режиме «Точность» Gemini времени не возвращает вовсе (по документации
  Google таймкоды несовместимы со словарём и снижают точность), поэтому отметка времени в
  расшифровке — это начало части. Границы частей садятся на паузы, а не падают по таймеру
  на середину слова.
- Сорвалась модель в повтор — участок переспрашивается половинами, а не списывается:
  срыв случается на длинном запросе. Не помогло — предупреждение называет точный отрезок,
  который остался без расшифровки.

## Сборка

```bash
xcodegen generate            # после любых изменений в project.yml или списке файлов
xcodebuild -project LoriLocal.xcodeproj -scheme LoriLocal \
  -destination 'id=<udid симулятора>' CODE_SIGNING_ALLOWED=NO test
```

На телефон — с автоматической подписью и своим Team ID:

```bash
xcodebuild -project LoriLocal.xcodeproj -target LoriLocal -configuration Release \
  -sdk iphoneos -arch arm64 -allowProvisioningUpdates \
  DEVELOPMENT_TEAM=<team> CODE_SIGN_STYLE=Automatic SYMROOT=<путь> build
xcrun devicectl device install app --device <udid> <путь>/Release-iphoneos/LoriLocal.app
```

# Общая папка IPA

Выпуск для IPA Shelf: `tools/release-ipa.sh`. Готовые сборки атомарно публикуются в iCloud Drive → **IPA Shelf**. См. [IPA_RELEASE.md](IPA_RELEASE.md). Сборка содержит неподписанный device binary для последующей подписи; это не подтверждение установки на iPhone.
