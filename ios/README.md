# Lori for iOS

Нативная personal-use версия Lori для iPhone.

- Рабочая папка: `Files/Lori/Workspace` в контейнере приложения.
- Ключ DeepSeek хранится в iOS Keychain и не попадает в исходный код.
- Модель может вызывать только валидированные локальные файловые инструменты.
- Локальный GigaAM добавляется отдельным Core ML модулем после измеренного теста на устройстве.
- Движок расшифровки выбирается в настройках: GigaAM v3, Whisper large-v3 turbo или движок Apple.
  Модели первых двух кладут руками в «Файлы» → Lori → `Models`; приложение их не докачивает.
  Как добыть модель Whisper — `design/whisper/README.md`.

Для генерации проекта: `xcodegen generate`.
