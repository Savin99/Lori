# Ключи для личной сборки

`APIKeys.local.json` содержит личные значения и исключён из Git. Формат — как
в `APIKeys.example.json`. Для текущей конфигурации нужны `elevenLabs` для
расшифровки и `assistant` для OpenAI (чат по умолчанию — GPT-6 Luna).
При первой установке сборки с ключом ElevenLabs выбран ElevenLabs; при обновлении
сохраняется ранее выбранный движок.
Пустые значения можно оставить пустыми. В поля вставляются сами API-ключи,
без префикса `Bearer`.

При сборке личного приложения для iPhone Xcode копирует значения в ресурс
`PrivateAPIKeys.plist`. Это работает и через `tools/release-ipa.sh`.
Значения не передаются аргументами команд и не печатаются в журнале.
В QA, симулятор и другой Bundle ID ресурс не включается; прежний ресурс
удаляется также при удалении локального JSON. Повреждённый JSON останавливает сборку.

Ключ, введённый вручную в Lori, имеет приоритет. «Вернуть встроенный ключ»
удаляет ручную замену из Keychain. Встроенные ключи доступны и после чистой
переустановки этой IPA; для их обновления нужна новая сборка или ручная замена
в настройках. Ранее выбранные провайдер и модель чата сохраняются.
Встроенный ключ используется только с официальным HTTPS-адресом своего сервиса.
Для своего прокси или другого провайдера ключ нужно задать в настройках вручную.

Ключи извлекаются из IPA: сборка с ними предназначена только для владельца.
Сохранённые только на iPhone ключи автоматически в локальный файл не переносятся.
