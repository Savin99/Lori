# Whisper large-v3 turbo на iPhone

Пятый движок расшифровки рядом с GigaAM, Apple, OpenAI и Gemini. Состояние на 31 августа 2026.

## Чем крутится

Пакет [`argmaxinc/argmax-oss-swift`](https://github.com/argmaxinc/argmax-oss-swift) 1.1.0,
продукт `WhisperKit` — Core ML-реализация Whisper с работой на Neural Engine и пословными
временами. Это первая сторонняя зависимость проекта; выбрана вместо своего экспорта в Core ML
потому, что у Whisper авторегрессивный декодер с KV-кешем и BPE-словарём на 51866 токенов —
на порядок больше работы, чем ушло на GigaAM, где декодер уже был написан.

## Где лежит модель

Веса в сборку **не** входят и приложением **не** докачиваются: `download: false` в
`WhisperKitTranscriber`. Расшифровка обязана работать без сети, а 600 МБ по мобильной сети
за владельца никто решать не должен.

Папку кладут руками: «Файлы» → «На моём iPhone» → Lori → `Models`. Имя папки не важно,
лишь бы в нём было слово `whisper`; внутри должны лежать `MelSpectrogram.mlmodelc`,
`AudioEncoder.mlmodelc`, `TextDecoder.mlmodelc`.

Собрать папку на Mac и положить её в симулятор:

```bash
python3 design/whisper/fetch_model.py     # в ~/Library/Caches/lori-models/whisper-large-v3-turbo
./design/whisper/seed-model.sh <udid>     # оттуда же — в контейнер симулятора
```

Модель качается **один раз**: кэш лежит рядом с моделями GigaAM, и повторный запуск
`fetch_model.py` сверяет размеры файлов с HuggingFace и не качает ничего. Это же и проверка
целостности — недокачанный файл размером не сойдётся и приедет заново.

Папка — 618 МБ, 24 файла: веса (`AudioEncoder.mlmodelc` 410 МБ, `TextDecoder.mlmodelc` 194 МБ,
`TextDecoderContextPrefill.mlmodelc` 12 МБ, `MelSpectrogram.mlmodelc` 392 КБ), оба файла
токенизатора, `config.json` и `generation_config.json`. Все размеры сверены с HuggingFace
31 августа 2026.

**Путь контейнера перечитывать каждый раз** (`xcrun simctl get_app_container <udid>
ru.ilyaqa.lori.local data`): после переустановки приложения каталог получает новый UUID —
данные переносятся, а сохранённый путь перестаёт существовать.

Варианты turbo в репозитории `argmaxinc/whisperkit-coreml`:

| Папка | Размер |
| --- | --- |
| `openai_whisper-large-v3-v20240930_turbo_632MB` (по умолчанию) | ~630 МБ |
| `openai_whisper-large-v3-v20240930_turbo` | ~1.6 ГБ |
| `openai_whisper-large-v3_turbo_954MB` | ~950 МБ |

## Грабля: токенизатора в папке модели нет

WhisperKit ищет токенизатор в самой папке модели и, не найдя, идёт за ним на HuggingFace —
то есть без сети расшифровка молча не начнётся. В папках `whisperkit-coreml` токенизатора нет,
он лежит в `openai/whisper-large-v3`. Скрипт добирает оттуда два файла:

- `tokenizer.json` — по нему пакет решает, что токенизатор локальный;
- `tokenizer_config.json` — из него читается класс токенизатора, без него разбор падает.

`WhisperModelSet.missingTokenizerFile()` проверяет оба и называет недостающий в тексте ошибки,
чтобы это не выглядело как поломка расшифровки.

## Как режется длинное аудио

Окно Whisper — 30 секунд, поэтому куски берутся по 28 с общим `AudioChunker`: разрез сдвигается
к тишине, куски перекрываются, дубли из перекрытия отбрасываются по времени в `TranscriptAssembler`.
Своя нарезка вместо встроенной в WhisperKit VAD выбрана ради честного прогресса: «3 из 10»
считается только тогда, когда число кусков известно заранее.

Слова Whisper отдаёт с ведущим пробелом и знаками препинания, приклеенными к слову;
`WhisperTranscript.words` убирает пробел, сдвигает время на начало куска и сохраняет пунктуацию —
по ней `TranscriptAssembler` режет реплики.

## Что не проверено

**Ничего не собрано и не запущено.** На Mac mini владельца в Xcode 26.6 не установлена платформа
iOS: `xcrun simctl list runtimes` пуст, симуляторов нет ни одного, `xcodebuild` отвечает
«iOS 26.5 is not installed». Проверен только синтаксис файлов (`swiftc -parse`).

Чтобы собрать и прогнать тесты, нужно вернуть платформу — это несколько гигабайт загрузки:

```bash
xcodebuild -downloadPlatform iOS
```

После этого непроверенным остаётся главное: скорость и качество turbo на настоящем iPhone
и то, как он ведёт себя на тишине (Whisper склонен выдумывать текст там, где речи нет).
