# Референсы Lori — библиотека расшифровок

## Назначение

Lori — локальная библиотека аудиотрансляций и расшифровок. Здесь нет чата с
агентом, поиска по ИИ или генеративных заметок: приложение показывает исходную
расшифровку и короткий детерминированный обзор её ключевых фрагментов.

## Исходный визуальный ориентир

Шесть приложенных пользователем экранов Granola от 18.08.2026:

1. тёмный почти угольный фон и мягкие серые карточки;
2. выезжающая слева панель папок;
3. полноэкранная форма создания папки;
4. домашняя страница со встречами, сгруппированными по датам;
5. не используется: это экран ИИ-поиска;
6. экран чтения одной расшифровки с кнопкой Share.

Мы берём только язык интерфейса, а не логотип, статус-бар, аватар или название
исходного приложения. Целевая ширина — 393 CSS px, базовая высота — 852 px.

## Реализованные поверхности

| Поверхность | Что должно быть |
| --- | --- |
| Главная | Расшифровки по дням, поиск, добавление записи, быстрый доступ к папкам. |
| Папки | Список, поиск, создание новой папки, привязка расшифровки. |
| Карточка записи | Дата, папка, короткий обзор, полный исходный текст. |
| Поделиться | Экспорт исходной расшифровки в Markdown или PDF. |

## Палитра и ритм

- фон: `#252525`;
- карточки: `#292929`;
- основной текст: `#F4F3EF`;
- вторичный текст: `#A5A5A0`;
- действие Share: `#F1F0E9`;
- оливковый акцент: `#515A1D`;
- радиусы карточек: 22–24 px, внутренние отступы: 14–16 px.

Для крупного заголовка используется `Newsreader`, для интерфейса — `DM Sans` с
системным фолбэком. Иконки — один набор Tabler Icons; вручную нарисованных SVG
и эмодзи в интерфейсе нет.

## Исключённые старые материалы

Старый борд мобильного чата и его CSS удалены вместе с описанием агентного
сценария. Исходные личные расшифровки и папка `wiki/` не являются UI-методом и
сохранены как данные, но приложение их не индексирует и не показывает.
